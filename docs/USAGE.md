# M12P Watchface 使用说明

适用环境：华强北 M12P（368×448、Android 8.1、无 Wear OS/GMS），其他小屏安卓手表理论上兼容（界面按画布宽度自适应缩放）。

## 一、安装

**方式 1：ADB（推荐，电脑操作）**

```bash
adb install -r watchface-x.x-debug.apk
```

**方式 2：手表直接下载**

1. 手表与电脑连同一 Wi-Fi
2. 电脑起一个简易下载服务：
   ```bash
   python3 -m http.server 8080   # 在 APK 所在目录执行
   ```
3. 手表浏览器打开 `http://电脑IP:8080/watchface-x.x-debug.apk`，下载后点击安装
4. 安装时允许「未知来源」

## 二、启用表盘桌面（关键步骤）

本 app 不是普通应用，它是一个**桌面（Launcher）**。启用方式二选一：

- **方式 1**：打开「表盘」app → 预览页 → 点「设为主屏幕（桌面模式）」→ 系统设置里选择「表盘」
- **方式 2**：按手表 Home 键，弹出「选择主屏幕应用」时选「表盘」并勾选「始终」

生效后按 Home 键回到的就是表盘本身。如果设置后主屏没变，**重启一次手表**即可生效。

## 三、接通血糖数据

### 数据源 A：AndroidAPS（推荐）

1. 手表上安装 AndroidAPS
2. AAPS → 配置 → 同步类插件 → 启用 **Tizen** 插件
3. 等待下一次 CGM 读数（5 分钟一次），表盘自动出现血糖值

**验证方法**：打开「表盘」app → 嗅探页。收到广播后此页会显示广播原文（`glucoseMgdl=...` 等字段）。嗅探页有内容 = 数据链路通。

### 数据源 B：欧态 OTTAI

1. 手表安装欧态 app 并连接 CGM
2. 「表盘」app → 设置页 → 数据源切到「欧态」
3. 欧态广播的是原始 mmol 值，若与实际 CGM 读数有固定偏差，用设置页「偏移」加减修正（步进 0.1，范围 -2~5）

### 单位切换

设置页「显示单位」：mmol/L ↔ mg/dL。AAPS 源推荐 mmol/L（与 AAPS 显示一致）；欧态源按需选择。

## 四、日常操作

| 操作 | 方式 |
|---|---|
| 表盘 ↔ 应用列表切换 | 按住屏幕**左右拖动**，松手自动吸附 |
| 启动应用 | 应用列表九宫格中点击图标 |
| 长按应用 | 弹出菜单：固定到快捷入口 / 应用信息 / 卸载 |
| 隐藏血糖（隐私） | 点击血糖数字旁的**眼睛图标**，再点恢复 |
| 编辑设置 | 表盘右上角「≡」（编辑模式下变「×」用于退出） |
| 换背景图 | 预览页「更换背景图」→ 系统图库选图 |
| 背景显示模式 | 预览页切换：铺满全屏（裁剪）/ 完整显示（留边） |
| 调整背景位置 | 预览页 ◀ ▶ ▲ ▼ 微调（铺满模式生效） |
| 界面字号 | 设置页「界面字号」：标准 / 大 / 特大 |

## 五、个性化配置

- **应用白名单**：设置页「选择应用」勾选后，应用列表只显示勾选的应用；全部不勾 = 显示所有应用
- **快捷入口**：设置页「选择快捷入口」勾选（最多 4 个，勾选顺序即底部排列顺序）；全部不勾 = 默认 AAPS/欧态/系统设置

## 六、常见问题

**1. 嗅探页一直空白，表盘没有血糖**
- 确认手表 AAPS 已启用 Tizen 插件
- 确认欧态 app 正在发数据（设置页切数据源试试）
- AAPS 前台运行中，CGM 5 分钟一跳，等 1~2 个周期

**2. 设为主屏幕后按 Home 还是原桌面**
- 重启手表；仍不行用 ADB 强制：`adb shell cmd package set-home-activity io.github.zhantaopin.watchface/io.github.zhantaopin.watchface.MainActivity`

**3. 背景图方向不对 / 只显示一块**
- v1.7 起已自动应用 EXIF 方向，重新选一次图
- 铺满模式会裁剪超出部分（照片比例与屏幕不一致是数学必然），用「调整背景位置」选择保留区域，或切换「完整显示」模式看整图

**4. 电池/内存**
- 表盘每分钟一帧 + 灭屏停刷，常态耗电可忽略；如需监控整机负载，配合 sysmon 类工具查看

## 七、卸载

系统设置 → 应用 → 表盘 → 卸载（桌面应用可直接卸载；卸载后主屏幕恢复系统默认）。
